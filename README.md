# TWEAKARC — Code Showcase

Selected C# source code from TWEAKARC, a 2D physics puzzle game designed and developed in Unity.

This repository is a code showcase and does not contain the complete Unity project, game assets, scenes, or level files.

## Editor Tools

Custom Unity Editor tools used to create levels and store level data as JSON.

- `LevelCreator.cs` — Defines the level creation data and functionality.
- `LevelCreatorEditor.cs` — Custom Unity Editor interface for creating and saving level data.

## Runtime

Runtime systems used to load levels and control the game's state and progression.

- `Level.cs` — Defines the structure of level data.
- `LevelManager.cs` — Loads and manages level data during gameplay.
- `GameStateManager.cs` — Controls the main game states and transitions.
